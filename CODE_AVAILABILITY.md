# Code availability statement

Suggested manuscript wording after the repository is pushed and archived:

> Custom scripts used for data processing and analyses in this study are available at [GitHub repository URL] and have been archived in Zenodo (DOI: [Zenodo DOI]).

Do not insert the placeholder URL or DOI until the GitHub repository and Zenodo archive are public and the release has been checked.

## Release checklist

- Confirm the repository name and visibility.
- Review every committed file for private paths, credentials and unintended raw data.
- Add a license.
- Create a versioned GitHub release/tag.
- Create the Zenodo archive from that specific release.
- Replace the manuscript placeholders with the permanent GitHub URL and Zenodo DOI.
